# Day 4: Functions, Dictionaries and Classes

Topics: `def`, `return`, default arguments, `dict`, `try` / `except`, `class`.

| File | Exercise |
|---|---|
| `functions.py` | Write `add`, `is_even` and `final_price` (with a default tax of 15%) and print their results |
| `students.py` | Loop over a dictionary of grades and print the average and the best student |
| `word_count.py` | Count how many times each word appears in a sentence (dictionary) |
| `product.py` | A `Product` class with a `show()` method, then print a list of products and their total |
| `safe_input.py` | A `get_number()` function that keeps asking until the user enters a valid number (try / except) |
| `contacts.py` | A small contact book with add / find / list / quit commands (dictionary + while loop) |

## Run

    python3 product.py
