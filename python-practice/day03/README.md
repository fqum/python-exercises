# Day 3: Loops and Lists

Topics: `list`, `for`, `while`, `range`, `break`.

| File | Exercise |
|---|---|
| `prices.py` | Loop over a price list and print the total, highest price and average |
| `table.py` | Print the multiplication table (1 to 10) of a number |
| `countdown.py` | Count down from a number to 1, then print `Go!` (while loop) |
| `guess.py` | Guess the secret number (7) with `Too high` / `Too low` hints and an attempt counter |
| `fizzbuzz.py` | FizzBuzz from 1 to 30 |
| `cart.py` | Read prices until 0, then print the item count and total (list + while) |

## Run

    python3 fizzbuzz.py
